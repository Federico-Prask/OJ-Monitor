# OJ-Monitor 监视列表功能使用指南

## 功能概述

监视列表是一个实时爬虫系统，可以监视多个洛谷用户的提交记录，并在有新提交时实时通知。

## 工作原理

1. **前端管理**：使用 LocalStorage 存储监视列表配置
2. **后端爬虫**：定期（5 秒）爬取洛谷用户的最新提交
3. **实时通知**：前端轮询获取未通知的新提交，并显示通知

## 使用步骤

### 1. 创建监视列表

1. 打开前端，进入"🎯 监视列表"标签页
2. 在"创建新的监视列表"区域输入：
   - 列表名称（例如"班级A"）
   - 用户名（例如"ricky_lin"），点击"添加用户"
   - 可以添加多个用户
3. 点击"创建监视列表"

### 2. 启动监视

1. 找到刚创建的监视列表
2. 点击"▶️ 启动"按钮
3. 后端开始每 5 秒爬取一次用户的最新提交

### 3. 接收通知

1. 前端每 3 秒轮询一次后端获取新提交
2. 当检测到新提交时，会在"🔔 新的提交通知"面板显示
3. 如果浏览器允许通知，还会显示桌面通知

### 4. 管理监视列表

- **添加用户**：在监视列表中输入用户名后回车
- **删除用户**：点击用户名旁的"×"
- **停止监视**：点击"⏹️ 停止"
- **删除列表**：点击"🗑️ 删除"

## API 接口

### 启动监视列表爬虫

```
POST /api/watchlist/start
{
  "usernames": ["user1", "user2"],
  "intervalSeconds": 5
}
```

### 停止监视列表爬虫

```
POST /api/watchlist/stop
```

### 获取未通知的新提交

```
GET /api/watchlist/notifications
```

返回示例：
```json
[
  {
    "username": "ricky_lin",
    "problemId": "P1001",
    "problemTitle": "A+B Problem",
    "difficulty": 0,
    "difficultyName": "灰",
    "submitTime": "2025-11-28T10:30:00"
  }
]
```

### 标记提交为已通知

```
POST /api/watchlist/mark-notified
{
  "username": "ricky_lin",
  "problemId": "P1001"
}
```

## 技术细节

### 后端组件

- **LuoguWatchlistCrawler**：真实的洛谷爬虫，爬取用户提交记录
- **WatchlistCrawlerService**：管理后台爬虫任务和通知队列
- **WatchlistController**：暴露 API 接口

### 前端组件

- **useWatchlistStorage**：LocalStorage 存储管理
- **watchlistService**：API 调用服务
- **WatchlistManager**：UI 组件，提供完整的管理界面

## 注意事项

1. **爬虫频率**：每个用户每 5 秒爬一次，多个用户间隔 0.5 秒避免频繁请求
2. **数据存储**：只在 Cookie（LocalStorage）中存储监视列表配置，提交记录存储在内存中
3. **浏览器通知**：需要用户同意浏览器通知权限
4. **网络连接**：需要能够访问洛谷网站

## 故障排除

### 爬虫不工作

1. 检查后端是否正常运行（访问 http://localhost:5000）
2. 检查用户名是否正确（可在洛谷网站验证）
3. 查看浏览器控制台是否有错误信息

### 通知不显示

1. 检查浏览器通知权限
2. 确保前端在运行
3. 检查网络是否正常

### 爬虫过于缓慢

1. 减少监视用户数量
2. 增加轮询间隔（在启动时修改 intervalSeconds）
